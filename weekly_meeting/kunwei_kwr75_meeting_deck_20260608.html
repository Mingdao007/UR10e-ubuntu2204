External-loop control

External-loop line-following demo completes and returns home

This demo reproduces the paper-style architecture in a small straight-line task: Python computes Cartesian correction commands from the Kunwei wrench and measured TCP pose, while the UR controller executes those commands and handles IK through speedl. The run crossed the 143.247 mm success threshold, reached 143.618 mm max progress, kept XY path-error p95 at 0.138 mm, then unloaded, retracted, and returned home. The line-following part is successful demo evidence; contact-force Fz control still needs tuning.
