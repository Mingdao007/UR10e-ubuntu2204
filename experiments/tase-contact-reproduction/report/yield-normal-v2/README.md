# NO-v2：共同法向估计器的开发消融

保留旧估计器为默认；NO-v2 是独立参数版本，尚未采用。
所有实验固定 DSFC 机械参数、共同外环、QP 与原平台模型，不调整控制器。
数据仅用于 development，不能作为最终独立 holdout 或实机验收。

旧估计器同时使用未归一化的运动梯度与合力方向修正。切向摩擦使合力方向
不等于曲面法向；先前 audit 已显示约 6.76° 的估计误差高于 1.42° 的 approach 先验。
但关闭偏置和增强运动更新是两项变化，必须分别检查，不能先假定哪项有益。

NO-v2 的状态仍只有固定 base 坐标下的单位法向 n 与 approach。
观测输入为实际 TCP 线速度 v、测得环境力 f 及接触标记，没有曲面真值输入。
接触与切向激励门控沿用原设置。候选更新为：

    g = gamma (n^T v) (I - n n^T) v / max(v^T v, epsilon^2)
    g <- g * min(1, omega_max / ||g||)
    n_next = normalize(n - dt g)

其中 gamma=1/s、epsilon=0.002 m/s、omega_max=0.1 rad/s；力方向修正关闭。
零梯度不进行除零缩放。完整参数写入 controller identity，旧版默认参数与
算术顺序保持不变；完整快照回放读取实际 estimator 参数。

独立平面 fixture 显示：两个切向方向可恢复法向，单一切向方向留下不可观测分量；
在激励门限以上，归一化更新不再随速度平方衰减。接触丢失时保持状态。
这些检查不证明闭环任务有效：法向压入/释放速度也在 v 中，并不满足理想切向约束。

## 已观察到的负结果

NO-v2 四个闭环完整周期均执行完毕，但性能不足以采用：刚性材料的法向干预中，
法向误差 RMS 为 14.83°，接触峰值约 9.74 N，路径 RMS 约 13.0 mm。
正常工况的法向/姿态指标改善不能抵消这些恶化。原始数据与完整状态保留。
配对 NO-forceoff-v1 只关闭力方向修正，保持原始运动更新，用于区分两项修改。
所有单元，包括代价与失效指标，见 [results.md](results.md)。

记录程序在 NO-v2 最后阶段试图用排他写入覆盖启动清单而报错；四个轨迹及
summary 已先保存并逐个校验 SHA。保留原始启动清单，单独记录完成恢复说明，
没有重跑或把非零进程退出码改成零。脚本已改为分开保存 start 与 completion。

最终研究仍需处理接触变形/外界干预与切向运动的可辨识性；当前不能把该候选
作为共同模块推广，也不能以初始先验较准确代替未知曲面法向估计的证明。


## 配对消融的结论

NO-forceoff-v1 将两组材料的 nominal 法向 RMS 降到 1.36° / 1.29°，
但路径 RMS 升到 5.04 / 11.83 mm，接触峰值升到 6.07 / 5.96 N。
它不能作为已完成的共同模块修复。同一腕部合力既包含接触摩擦也包含外界作用，
当前外环把所有切向力都送入柔顺项；这会产生任务偏差。
旧估计器向合力倾斜时会同时削弱被投影出的切向力，因此原先较小的路径误差
不能被孤立解释为更好的未知曲面控制。

下一步优先处理共同外环中接触摩擦与受力让步的折中，并保持 SFC/DSFC/MSFC
共用相同机制。不能用不可观测的人类施力“真值”来消除摩擦，也不能在干预时
重置 memory。局部切向约束 n·v=0 只在法向压入/释放可忽略时成立，不能将
平面 fixture 的收敛当作恒力曲面任务的证明。

本轮 8 个新完整周期与 4 个既有配对单元均保留。155 项 contact 回归检查通过；
新参数版本的完整状态短程回放通过，原默认 estimator 算术与参数 identity 保留。
没有实机执行，最终公平预算与 holdout 未开始。共同模块尚未达到 pilot 条件。


## 力平衡复核

额外诊断选取 PATH >=5 s（posthoc，不替代完整窗口指标）。关闭偏置时，
两种材料的切向力 RMS 为 0.594 / 1.429 N，路径恢复力为 0.599 / 1.442 N，
两者相加后的 RMS 仅 0.020 / 0.029 N；对应估计坐标系内路径 RMS 为
4.99 / 12.02 mm。旧估计器投影出的切向力仅 0.076 / 0.170 N。
这些记录支持摩擦力与路径恢复力形成偏移平衡的机制解释，见 friction-balance.json；
它仍是当前接触模型内的机制证据，不能直接作为实际摩擦辨识结果。
