# Main 对 Fable 第一轮讨论的核验

Native metadata 已确认 claude-fable-5-1；启动参数为 xhigh，经 Ubuntu Homepool。
一次讨论已完成，不再为本轮修改反复调用。模型建议是 advisory，不是验收结论。

## 已独立核对并采纳

- GM-v1 的 2×2 已实测：identity metric 不消除原 gain 下的法向振荡/步长敏感性，
  gain 减半在 memory 开关两臂均有改变。这支持参数相关的闭环机制，不能算 memory 创新。
- 改变输出 gain 同时改变 command-velocity 坐标下的等效质量及阻尼系数。
  因此 main 的“gain 减半”描述指实际参数操作，不声称只改变一个传递函数系数。
- Main 从完整 MSFC nominal receipt 独立重算法向误差：估计 6.7604° RMS，
  approach 先验 1.4174° RMS。共同法向估计模块需要优先修复与辨识能力检查。
  独立计算见 ../../yield-transfer-v1/normal-estimate-audit.json。
- 保留入口全过程指标；可以另列稳定段解释机制，但不能删除启动/饱和段来美化结果。
- plant 的关节速度硬裁剪是未辨识的模型假设，应记录、审计其影响，不能当作实际
  UR 动力学保证。Main 独立计算 nominal 的采样端点命中 10/31416 ticks；
  中间子步可能遗漏，不能据此断言没有裁剪。

## 需收窄或尚未证明的说法

- “任何现有场景都不能激励 memory”与保留的切向数据不符：metric 最小特征值
  可到 0.7868。法向激励较弱并不意味着所有方向不可辨识。
- “不是积分失效”“闭环对初值不敏感”“只要极限环存在逐点判据不可能通过”
  都比当前有限轨迹/网格/单个孪生扰动支持的范围更强。相位漂移是合理解释，
  不是全局数值或稳定性证明。保留未对齐误差；对齐结果只能作诊断，不能替代验收。
- 不把 Kz=40 的跨方法数据当作 Kz=0 对照。TR-v1 已补齐 Kz=0、相同积分设置
  的 SFC/DSFC 法向单元，避免通过“投影上不直接进入法向”忽略闭环耦合。
- m×2 可作为后续诊断，但它也改变惯性和阻尼比，不能用二分结果唯一归因。
  当前优先修复已实证的共同估计器问题，不为讨论建议无限扩展参数搜索。
- Fable 提出的 0.3 N 振幅门槛尚未成为预注册验收标准；它是在看到数据后提出的。
  可另加更严的振荡指标，但不得回写原方案、放宽原阈值或将当前数据称为独立验证。
