# 讨论：MSFC 增益 / memory 消融能否隔离法向环敏感度（iteration 1）

角色：advisory，非阻塞，无 live authority。所有观测均为 DEVELOPMENT 数据，不是 holdout；无硬件动作，未改代码/配置/其他报告，未提交。
本目录 `data/` 为从既有 receipt 派生的数字，`scripts/` 为可复算脚本。三次 advisory 离线运行（孪生扰动 ×2、plant16 ×1）只写入 `/tmp/ygm/`，SHA-256 见 `data/advisory-runs-sha256.txt`；它们是诊断，不是 retained receipt。

## 0. 结论摘要

1. **3.60 N 的 MSFC 法向敏感度是极限环相位漂移，不是积分失效。** 持续法向场景中 MSFC 法向环进入 2.0–2.5 Hz、±1.1–1.5 N 的自持振荡并伴随接触丢失，释放后仍持续到 ≈52 s。plant4/plant8 波形做最优时移对齐后残差从 1.9 N 降到 0.12–0.47 N；plant16 对 plant8 的相位漂移速率比 plant8 对 plant4 小约 2.5–3 倍（收敛），但逐点最大差仍有 2.33 N。
2. **闭环对初值不敏感。** 1e-9 rad 关节扰动的孪生运行与 receipt 逐点差 1.5e-6 N、3.4e-10 m。相位漂移是离散化对极限环周期的系统性偏移，不是混沌。
3. **冻结参数下 memory 几乎不活跃。** 整个法向场景 metric 最小特征值仅降到 0.9746；且非线性阻尼项本身只占法则输入的 1–2%（中位）。三种法则在法向环工作区内都退化为纯积分器 + 3 mm/s 限幅，差别只剩 g/m 与 mu/g³。
4. 对 Main 的 2×2：λ_min=1 臂是有效证伪，但预期为空结果，只能说明"当前参数下 memory 不活跃"，不能说明 memory 无害或无益；g×0.5 臂预期显著降低敏感度，但 g 同时改变回路增益（×0.5）、v-空间三次阻尼（×8）和亚线性项（×1.41），不能把效果单独归因于"增益"。
5. 共享模块有三个先于 proposal 的问题：限幅后无 anti-windup；法向估计器误差 6.7° RMS，比不估计（approach 先验 1.4°）差近 5 倍，并把 ≈0.6 N 偏置注入切向（≈5 mm 路径误差）；入口瞬态占 nominal 指标约一半。
6. 下一步最小可证伪步骤：在 Main 的 2×2 上补一臂 **m×2（g、mu、a 不变）**，并为每臂预注册"极限环是否存在"的不变量判据（见 §6）。

## 2. 对 Main 消融设计的评估

- **能否隔离？部分。** 2×2 能给出对比：若 g×0.5 消除自持振荡而 λ_min=1 不改变任何不变量，则"memory 导致敏感度"被证伪，"g 相关"被支持。它不能区分回路增益（g/m）与 v-空间阻尼/windup 界（mu/g³）——两者被 g 同时改变。
- **λ_min=1 臂的预期与解读。** 预期不变量差异 <1%。但注意：因极限环相位对任何持续微小改动都敏感（步长即例），λ_min=1 臂在法向场景与 active 臂的**逐点**差仍可能达 0.05–0.1 N，这与"memory 不活跃"相容；应看对齐残差和不变量。空结果不是"memory 安全/有效"的证据，只是"冻结参数下 memory 未被激励"。
- **g×0.5 臂的预期。** 交越降到 ≈2.1 Hz，windup 界从 16 降到 8 mm/s；预期振幅和接触丢失显著下降，plant4/8 逐点差远低于 1 N；若极限环消失，逐点差应回到 ≈0.05 N 级。同时切向让步/恢复指标会变（g 也管切向），需一并报告，不能只报法向。
- **判据。** 不建议放宽逐点门槛；建议保留它用于非振荡段，并**增加**（更严）一项 pilot 前置条件："持续法向释放后法向环无自持振荡"（36–52 s 带通 1.2–4 Hz 振幅 <0.3 N 且无接触丢失）。诊断层面补充：对齐残差、不变量随 4/8/16 的收敛、相位漂移斜率。
- **缺口。** Kz=0 的 SFC/DSFC 持续法向对照未跑；Kz 不进法向环，可先引用 Kz=40 数据，但正式表需补齐（4 次运行）。

## 3. 相位漂移 vs 积分失效：判别程序

1. **孪生扰动**（1e-9 rad，同 substeps）：差异不增长 ⇒ 非混沌，差异为系统性；本例 1.5e-6 N。
2. **对齐残差**：在无事件窗口做 ±1 周期时移扫描；残差坍缩（本例 1.9→0.1 N）⇒ 相位；不坍缩 ⇒ 幅值/拓扑差异。
3. **Richardson**：4/8/16 下对齐残差与相位斜率应按 ≈2 倍收缩（本例 2.5–3 倍）；不变量（接触丢失时长、次数、饱和、峰值、振幅）应单调收敛；若比值 ≈1 或不变量跳变 ⇒ 积分失效或事件（冲击、裁剪）未解析。
4. **事件对照**：接触丢失/关节裁剪/限幅切换的时刻表；差异首次放大是否与首个事件重合（本例 24–26 s 饱和先于 26.3 s 接触丢失，振幅已在增长，事件是放大器不是起点）。

## 4. 物理误导性假设与未控混杂

1. 法则与 3 mm/s 法向限幅之间无 anti-windup，内部状态超限幅 2 倍并靠三次项兜底；windup 界随 g 变化 5–12 倍。这是共享模块缺陷，不是 proposal 特性。
2. plant 在叠加接触加速度后对关节速度做 0.05 rad/s 硬裁剪，与控制器 QP 边界同值；真实 UR 无此裁剪。它在 40–52 s 极限环内激活 ≈4% tick，是步长相关的非光滑源。
3. `state_age_s` 恒为 0，freshness 只做分类不做实际延迟；真实链路 ≥2–8 ms 会在 2.5 Hz 再吃掉 2–7° 裕度。当前仿真对法向环稳定性是**乐观**的。
4. 法向估计器劣于 approach 先验（6.7° vs 1.4°），并把 ≈0.6 N 偏置注入切向，主导路径误差；"未知曲面 + 姿态随动"在这个曲面上目前是负贡献。
5. 入口协议留下已饱和的法则状态，前 12 s 贡献 nominal 力 MAE 的一半、路径 RMS 的一半；"匹配 nominal 精度"应以稳态段或加长 settle 后计。
6. 外力经传感器与接触力同路进入控制器，控制器调节的是总力；因此 memory 的输入残差被结构性抹平（§1.3），持续法向"让步"实际上是接触力被压到 2.5 N，再叠加自持振荡即丢接触。
7. 单边弹簧阻尼冲击（80 N·s/m 的闭合项在接触瞬间跳变）与显式 Euler 使冲击时刻按步长量化。
8. 材料参数（8000 N/m、μ 0.15）与 PI 伺服均未辨识；三方法的 g 由 6 s nominal 评分分别选定，导致 v-空间阻尼相差一个数量级——**方法间差异与增益选择完全混杂**。

## 5. 对"有意义贡献 / 可辨识实验"缺什么

- 当前参数下 SFC/DSFC/MSFC 在法向环内不可区分（均为积分器），在切向环的差异由 mu/g³ 解释，memory 调制 ≤2.5% 且输入被抹平。因此现有矩阵**无法辨识 memory 的贡献**，无论正负。
- 需要：(a) 以 v-空间等效参数或匹配回路带宽（k g/m 相同）做方法比较，而不是各自按 nominal 评分选 g；(b) 一个能真正激励 memory 的输入定义或场景（例如 h 由未被调节的量驱动，或场景中存在不能被总力调节抹平的持续残差），否则 MSFC 的差异化机制在协议内不可观察；(c) 预注册不变量与"无自持振荡"门槛；(d) 先修共享模块（windup、估计器、入口 settle）再比较，修复计入 baseline，不计入创新。

## 6. 下一步最小可证伪步骤（一步）

在 Main 的 2×2（g×{1,0.5} × λ_min∈{0.027,1}）上**补一臂 m×2（g、mu、a、memory 参数不变）**，法向场景 plant4/8 各一次（≈1 min/次），并对五臂统一计算：36–52 s 带通振幅、接触丢失时长/次数、饱和 tick、对齐残差、相位漂移斜率。预注册预测与判读：

| 结果 | 结论 |
|---|---|
| λ_min=1 臂不变量与 active 臂差 <1%，对齐残差 <0.05 N | memory 在冻结参数下不活跃；敏感度不归因 memory |
| g×0.5 消除自持振荡（振幅 <0.3 N、无接触丢失），m×2 也消除 | 原因是回路增益/相位裕度（k g/m） |
| g×0.5 消除、m×2 不消除 | 原因是 v-空间阻尼过弱 / 限幅 windup 界，应做共享 anti-windup 修正 |
| g×0.5 不消除 | 原因在共享模块（估计器耦合、裁剪、冲击），与法则参数无关 |
| λ_min=1 臂使振荡明显改变 | 我的"memory 不活跃"判断被证伪，需重查 h 的驱动量 |

不做无界控制器搜索；m×2 只是分离一个已被 g 混杂的自由度。plant16 已表明再细分不会让逐点判据通过，无需继续加 substeps。
