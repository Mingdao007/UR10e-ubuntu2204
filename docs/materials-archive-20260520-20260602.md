# UR10e Materials Archive: 2026-05-20 To 2026-06-02

This branch records UR10e bench materials collected and generated from
2026-05-20 through 2026-06-02. Treat it as a reusable evidence and reference
archive, not as one clean experiment result.

## What This Archive Contains

- UR10e bench notes, ROS 2 bring-up context, and workspace organization notes.
- Controller program backups, manifests, and copied vendor/controller files.
- OnRobot HEX-E manuals, USB/vendor backups, logs, plots, reports, and weekly
  meeting artifacts.
- Kunwei KWR75B trial sensor current-state notes and working roots.
- OnRobot HEX-E and UR RTDE no-motion force/torque logs, raw data summaries,
  plots, and reports.

## How To Use It

- Use dated folders, manifests, and report files as evidence sources for future
  UR10e, OnRobot, and Kunwei decisions.
- Keep vendor package timestamps separate from collection time; old file mtimes
  inside vendor backups do not mean the archive was collected then.
- Do not infer that every file here belongs to one experiment. The branch is a
  working archive spanning multiple related evidence-gathering sessions.
- Generated caches such as `__pycache__`, ROS `build/`, `install/`, and `log/`
  outputs should stay out of the archive commit.
- Large local raw recordings above normal GitHub blob limits stay on this
  workstation unless a separate Git LFS policy is approved. Keep reports,
  summaries, plots, manifests, and pointers in git.
